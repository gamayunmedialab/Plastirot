# Plastirot GitHub Pages Site

Static legal/support website for Plastirot.

## Publish on GitHub Pages

Option A: user site

1. Create a public repository named `<your-github-username>.github.io`.
2. Upload these files into the repository root.
3. Go to Settings -> Pages.
4. Set Source to Deploy from a branch.
5. Select `main` branch and `/root`.
6. Enable HTTPS when available.

Option B: project site

1. Create a repository, for example `plastirot-site`.
2. Upload these files into the repository root.
3. Go to Settings -> Pages.
4. Set Source to Deploy from a branch.
5. Select `main` branch and `/root`.

Use these in Google Play after publishing:

- Privacy Policy: `/privacy.html`
- Terms: `/terms.html`
- Support: `/support.html`
- Data Requests: `/data-requests.html`

Replace email/domain text if needed before release.
